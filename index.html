☁️ クラウド同期(Firebase)

        
スマホとPCで同じデータを使うには、無料のFirebaseに接続します。下の手順で取得した構成(firebaseConfig)を貼り付けてください。

        
        

          
          
        

        
未接続(この端末のみに保存されます)


        

          

            
            
            

              
              
            

            
初めての場合は「新規登録」。スマホとPCで同じメール・パスワードでログインすると、あなたのデータだけが同期されます。

          

          

            
            
          

        

      


      

        
🛠 Firebaseのセットアップ手順(初回のみ・約7分)

        
    
          
  1. FirebaseコンソールをGoogleアカウントで開き、「プロジェクトを作成」→ 名前は自由(例: meishi)。Google アナリティクスは無効でOK。
    2. 
          
  2. 左メニュー「構築」→「Authentication」→「始める」→ ログイン方法で「メール / パスワード」を選んで有効化して保存。
    3. 
          
  3. 左メニュー「構築」→「Firestore Database」→「データベースを作成」。ロケーションは asia-northeast1(東京)、本番環境モードで開始。
    4. 
          
  4. Firestoreの「ルール」タブを開き、中身を下のルールにまるごと置き換えて「公開」。これでログインした本人しか自分のデータを読み書きできなくなります。

    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}
    5. 
          
  5. プロジェクトの概要ページで 「</>」(ウェブ)アイコン をタップしてアプリを追加(名前は自由)。表示される firebaseConfig = { ... } をコピーして上の欄に貼り付け、「接続する」を押す。
    6. 
          
  6. 接続後に出るフォームでメール・パスワードを決めて「新規登録」。もう一方の端末でも同じ構成を貼り付けて接続し、同じメール・パスワードでログインすれば同期完了です。
    7. 
        

        
🔒 セキュリティについて: 名刺データはあなたのFirebaseプロジェクト内にのみ保存され、上のルールによりログインした本人以外は一切読み書きできません。アプリのHTMLファイルや公開URL自体に名刺データは含まれないため、URLを他の人が開いても空のアプリが表示されるだけです。

      


      

        
💡 使い方メモ

        
    
          
  1. 「読み取り・追加」タブでカメラ撮影 or 画像選択 → 自動でOCR(日本語+英語)します。文字認識には数十秒かかることがあります。
    2. 
          
  2. 読み取り結果は必ず確認・修正してから保存してください(OCRは完璧ではありません)。
    3. 
          
  3. 「CSV出力」でExcelでそのまま開けるCSV(UTF-8 BOM付き)をダウンロードできます。
    4. 
          
  4. OCRとクラウド同期にはインターネット接続が必要です。
    5. 
          
  5. アプリとしてインストール: iPhoneはSafariで開いて「共有」→「ホーム画面に追加」、AndroidはChromeのメニュー→「アプリをインストール」。アイコンから全画面アプリとして起動できます。
    6.
